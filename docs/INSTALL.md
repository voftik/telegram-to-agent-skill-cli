# Установка

Цель: от нуля до работающего CLI и навыка в агентах за несколько минут.

## Предпосылки

- Python не нужен заранее: `uv` сам приносит нужную версию.
- Свои Telegram API-ключи. Зайди на https://my.telegram.org, открой раздел
  «API development tools», создай приложение и забери `api_id` и `api_hash`.
  Чужие или дефолтные ключи повышают риск ограничений аккаунта.

## Обычная установка

```bash
uv tool install telegram-to-agent-skill-cli && tg setup
```

Нет uv? Поставь его одной командой с https://docs.astral.sh/uv/ или используй
npm-лаунчер: `npx telegram-to-agent-skill-cli` сам найдёт или предложит
поставить uv, затем установит CLI и запустит визард.

Визард `tg setup` делает всю настройку:

1. спрашивает `api_id` и `api_hash` и кладёт их в защищённый `.env`
   (каталог 0700, файл 0600);
2. проводит вход в Telegram: телефон, код из приложения, пароль 2FA;
3. ставит навык агентам: копия в `~/.agents/skills/tg`, симлинк в
   `~/.claude/skills/tg`, строки автовключения в `~/.claude/CLAUDE.md` и
   `~/.codex/AGENTS.md`;
4. предлагает запустить первую синхронизацию: `tg bootstrap start`
   переживает перезагрузки и убирает себя из автозагрузки после полного
   прохода;
5. показывает итоговую таблицу самопроверки.

Неинтерактивный режим для скриптов:

```bash
tg setup --yes --api-id 12345 --api-hash <32hex> --skip-login --skip-bootstrap
```

## Обновление

```bash
tg update
```

Команда сверяет установленную версию с PyPI, обновляет CLI и перекладывает
свежий навык. `tg update --check --yaml` только сообщает статус: агенты
читают поле `update.update_available` и предлагают обновление пользователю.

## Установка для разработки

```bash
git clone https://github.com/voftik/telegram-to-agent-skill-cli.git
cd telegram-to-agent-skill-cli
./install.sh
```

Скрипт ставит editable-версию через uv и запускает тот же визард. В
editable-режиме `tg skill install` по умолчанию симлинкает навык на чекаут,
и правки в `src/tg_cli/skill/` доезжают до агентов без переустановки.

## Безопасность

- Session-файл Telethon равен полному доступу к аккаунту: не копируй его
  между машинами, не клади в git и облачные папки. Каждая машина входит в
  аккаунт отдельно.
- Запись в Telegram (`send`, `edit`, `delete`) работает только с флагом
  `--confirm`; каждое подтверждённое действие CLI сначала фиксирует в
  журнале `mutations.log`.
- Каталог данных живёт вне облачной синхронизации сознательно: SQLite и
  облачные диски конфликтуют, а переписке нечего делать на чужих серверах.

## Состав пакетов

Wheel несёт CLI и навык: команда `tg skill install` работает без клона.
Sdist остаётся полным срезом исходников. Состав обоих артефактов проверяет
CI скриптом `scripts/check_dist.py`. npm-пакет содержит только лаунчер:
он ставит Python-пакет через uv и передаёт управление визарду.

## Linux и Windows

Каталог данных выбирается по платформе: XDG на Linux, LOCALAPPDATA на
Windows. install.sh и `tg bootstrap` рассчитаны на macOS и Linux; на
Windows поставь пакет через uv, а автозапуск первой синхронизации настрой
в Task Scheduler на команду `tg bootstrap run`.
