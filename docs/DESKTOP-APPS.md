# Настольные чат-приложения

Claude Code и Codex запускают CLI сами, им хватает навыка. Настольные
чат-приложения устроены иначе: Claude Desktop исполняет команды в
изолированной виртуальной машине, где нет ни `tg`, ни твоей базы, а
Perplexity вообще не умеет запускать команды. Их общая дверь к локальным
данным: локальные MCP-серверы, которые приложение запускает нативно.

Для этого в пакете есть `tg mcp`: крошечный read-only MCP-сервер поверх
локальной базы. Он отдаёт шесть инструментов (поиск, последние сообщения,
список чатов, паспорт чата, треды, ссылки), не открывает Telegram-сессию
и физически не умеет писать в Telegram. Синхронизацией занимается CLI на
хосте, поэтому мост не конфликтует ни с фоновым первичным синком, ни с
другими агентами.

## Быстрый путь

```bash
tg connect
```

Команда находит установленные приложения, говорит, какой файл и какая
запись будут добавлены, настраивает их и сама проверяет мост: запускает
ровно ту команду, которую будет запускать приложение, и делает пробный
MCP-хендшейк. Потом предлагает включить `tg autosync`, чтобы индекс
обновлялся сам. Тот же шаг встроен в визард `tg setup`.

Проверить состояние в любой момент:

```bash
tg connect status
```

## Claude Desktop

Конфиг: `~/Library/Application Support/Claude/claude_desktop_config.json`
на macOS, `%APPDATA%\Claude\claude_desktop_config.json` на Windows.

```bash
tg connect claude-desktop
```

Команда дописывает запись в `mcpServers`, не трогая чужие серверы; перед
изменением существующего файла создаётся копия `.bak`. После настройки
полностью перезапусти приложение (Cmd+Q, открыть заново): конфиг
перечитывается только при старте. Дальше просто спрашивай в чате
«что обсуждали в рабочем чате на этой неделе», Claude сам найдёт
инструменты `tg_*`.

Ручная запись, если предпочитаешь настроить сам:

```json
{
  "mcpServers": {
    "tg": {
      "command": "/абсолютный/путь/к/tg",
      "args": ["mcp"]
    }
  }
}
```

## ChatGPT desktop и Codex

ChatGPT desktop делит конфиг с Codex CLI: `~/.codex/config.toml`. Одна
запись покрывает и режим обычного чата (через MCP), и режим Codex
(который вдобавок умеет запускать `tg` напрямую через навык).

```bash
tg connect codex
```

Команда добавляет секцию, не трогая остальной файл, с копией `.bak` и
проверкой перед записью, что итоговый файл остаётся валидным TOML
(на Python 3.11 и новее):

```toml
[mcp_servers.tg]
command = "/абсолютный/путь/к/tg"
args = ["mcp"]
```

Перезапусти приложение или сессию Codex, чтобы конфиг перечитался.

## Perplexity

Приложение для macOS принимает коннекторы только через свой интерфейс,
файл конфига снаружи недоступен. Команда печатает пошаговую инструкцию
и готовый JSON (на macOS сразу копирует его в буфер):

```bash
tg connect perplexity
```

Шаги в приложении: Settings, затем Connectors, установить хелпер
PerplexityXPC по запросу, Add Connector, вкладка Advanced, имя `tg`,
вставить JSON, сохранить, дождаться статуса Running и включить `tg` в
Sources на главном экране. Работает только в приложении из Mac App
Store; Windows-версия локальные коннекторы пока не поддерживает.

## Свежесть данных

Мост только читает; данные в приложениях настолько свежи, насколько
свеж локальный индекс. Включи фоновое обновление:

```bash
tg autosync start            # каждые 15 минут
tg autosync start --interval 30
tg autosync status
tg autosync stop
```

Расписание переживает перезагрузки (launchd на macOS, systemd user timer
на Linux) и само уступает дорогу, пока идёт первичная синхронизация
`tg bootstrap`. Лог: `refresh.log` в каталоге данных.

## Другие приложения

Любому хосту с поддержкой локальных MCP-серверов хватит одной записи
из command и args:

```bash
tg connect manual
```

Команда печатает готовые JSON- и TOML-сниппеты с абсолютным путём.

## Если что-то не работает

- Приложение показывает мёртвый сервер: запусти `tg connect status`.
  Пометка broken значит, что прописанный путь к `tg` больше не
  существует (например, сменился способ установки); перезапусти
  `tg connect`, он пропишет актуальный путь и проверит мост.
- В конфиге обязателен абсолютный путь: GUI-приложения запускают
  MCP-серверы без shell и не видят PATH.
- Claude Desktop перечитывает конфиг только после полного выхода
  (Cmd+Q), свернуть и открыть окно недостаточно.
- Инструменты отвечают «index not found» или «index is empty»: на хосте
  ещё не было синхронизации. Запусти `tg bootstrap start` (полная) или
  `tg sync "название чата"` (один чат).
- Данные отстают: проверь `tg autosync status` и `refresh.log`.
